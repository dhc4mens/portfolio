Profile

インフラアーキテクトとして、オンプレミスからクラウドまで幅広い技術領域で設計・構築・運用を担当してきました。 現在は商社のデータ連携基盤の刷新に参画し、開発と並行して CI/CD と開発環境の整備を担当しています。 2025年7月にだいほう合同会社を創業し、ITコンサルティング・SRE支援・Web制作・IT教育を提供しています。 自社の AWS 基盤の開発・運用は、AI エージェント（Claude Code）を組み込んだ仕組みで回しています。 VMware/KVM等の仮想化基盤設計、RHEL等のOS基盤構築、AWS上でのインフラアーキテクチャ設計まで、 上流工程から実装まで一貫して対応可能です。

直近の実績（AI ログ監視） AWS Bedrock でアクセスログを日次分析する仕組み（CloudLogAI）を設計・構築し、自社サイトの監視として本番で毎日動かしています。 生成 AI モデルの提供終了で止まっていた分析を見つけて後継モデルへ移し、成功を返しながら本番に反映されていなかった CI を真因まで直すなど、作って終わりにせず、運用で見つけたことを直し続けています。
SRE基盤構築実績 Terraform IaC（infra/app層分離・週次drift検知自動起票・OIDC IAMロール保護）・ Lambda@Edge + Cognito認証基盤（SecretsManager統合）・SLI/SLO定義と CloudWatch アラーム・ ECS Fargate Runbook 4本・AWS Organizations による5アカウント構成への移行（本番影響なし）まで、SRE基盤を一から設計・構築し、継続して運用しています。

IaC（Terraform/Ansible）による自動化推進、大規模システム移行プロジェクトでの技術経験も豊富です。 2026年9月にはAWS Certified DevOps Engineer - Professionalを取得し、 CI/CD・IaC・監視を横断する実務知見に体系的な裏付けを得ました。2026年11月には AWS Certified Solutions Architect - Professional を受験予定です。 オンプレミス時代の深い知見とクラウドネイティブな技術の両方を活かし、モダナイゼーション案件で価値を発揮できます。
